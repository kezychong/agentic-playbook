# Agentic Starter Kit

Agentic Playbook — **by Kezy**

Give an agent a clear job and leave enough project memory for the next session. Start with a bounded workspace, turn the desired result into a checkable goal, and explain the system to the person who will use it.

## Start here

1. Read [setup and permissions](SETUP.md).
2. Follow the [workflow](WORKFLOW.md).
3. Copy the [blank worksheet](templates/workbook.md) into your own draft workspace.
4. Try the [fictional example and expected result](examples/company-a.md).

Suggested sequence: Start Project → Create Goal Prompt → ELI5.

## What is included, and what is not

These are adapted supplied methods with original supporting scripts, references and templates retained. Kezy maintains this repackage. No new licence grant is implied; preserve included third-party notices. These skills prepare local project scaffolds and explanations. They do not launch campaigns, create accounts or put an agent on an autonomous schedule.

Runtime status: **untested**. Local structural checks do not prove that a connector, model, installer or UI automation works. Choose available host/model capabilities at use time. Keep required companion folders when installing an individual skill; its README lists the dependency closure. Optional tools may require separate accounts and fees.
