# From a request to a reliable handoff

Agentic Playbook — **by Kezy**

## 1. Establish the project

Use [Start Project](start-project/skills/ap-start-project/SKILL.md). Identify whether the target is new or existing. Inventory first, then preview the four working folders and the six continuity files. Existing work keeps its location unless the owner approves a move. The included assets supply AGENTS, CLAUDE, LOG, DECISIONS, ROADMAP and STATE templates.

Make the goal specific enough that another session can tell whether it is done. STATE describes current truth and the next action; LOG records actual work; DECISIONS records the reasons behind choices. These are separate jobs, not six copies of the same summary.

## 2. Bound the agent's task

Use [Create Goal Prompt](create-goal-prompt/skills/ap-create-goal-prompt/SKILL.md) to turn the request into an objective, constraints, acceptance evidence and stop conditions. Specify which folders can change and what the agent should do when blocked. A good goal ends with inspectable output, not “improve everything.” Read the included goal-mode reference for the full method.

Review the resulting prompt. Starting a host's autonomous goal mode is a separate user action; the existence of a prompt does not start it. No external sending or publication follows from a local writing goal.

## 3. Explain the finished structure

Use [ELI5](eli5/skills/ap-eli5/SKILL.md) with the actual project files. Include the required ap-html-output companion supplied elsewhere in the collection. Explain one idea per visual section, give a 30-second version and glossary, and label unknowns. Keep the HTML self-contained and local. It should teach a newcomer how the project works without making up completed work.

## Completion check

A fresh session can identify the goal, current state, prior decisions and next action from the files. Every claimed deliverable exists. The explanation agrees with those files. Unfinished acceptance checks are named. No account, scheduler or live assistant profile changed during the sample.
