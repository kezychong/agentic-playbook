# Fictional walkthrough: Company A handbook

Agentic Playbook — by Kezy · Fictional sample, not an executed test

## Input

Company A wants a draft customer handbook. No customer data is supplied. The project is new. Required sections: Getting Started, Support Hours, Returns. Support hours and returns terms are not yet known. The only allowed action is writing local draft files in a new sample directory.

Trigger: “Set up a handbook project. Show the structure first, then turn the work into a bounded goal prompt. Do not publish anything.”

## Expected result

The preview includes the four source-defined working folders and all six continuity files. The owner approves the local scaffold. The goal prompt calls for three draft sections, names the draft directory, and requires unknown business terms to remain explicit questions.

A suitable objective is: “Draft Company A's three-section handbook using only the supplied facts. Mark Support Hours and Returns terms as awaiting owner input. Finish when all sections exist, the open questions are listed, and STATE names the next review step.”

DECISIONS records why unknown terms were not invented. STATE says “draft awaiting owner terms”; it does not say “published.” An ELI5 page explains the handoff using the real scaffold and includes a glossary for roadmap, state and decision record.

## Review

Check the output for invented hours, policies, customers or test results. None should appear. A sentence such as “Returns accepted within 30 days” fails this example because the input did not supply it.
