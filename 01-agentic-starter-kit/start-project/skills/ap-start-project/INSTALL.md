# Install Start Project

## What it does

Sets up a small memory system for a new or existing project. A fresh agent can see what the project is, what is true now, what was decided, what happened, and what should happen next.

## What you need

The Claude app or the Codex app, plus the downloaded `ap-start-project` zip.

## Install

Open your agent, attach the downloaded zip, and say:

> Install this Start Project skill so I can use it in every project on this machine. Verify that it is available, then tell me the exact sentence to start my first project.

Your agent handles the setup. You only need to install it once on each machine where you want to use it.

## Use it

For a new project, say:

> Start a new project for my customer referral program. Show me the proposed setup before you create anything.

For work already underway, say:

> Organize this existing project so a fresh agent can continue it. Preserve everything and show me the proposed changes before you write.

The skill will preview its plan and wait for your approval before changing the project.
