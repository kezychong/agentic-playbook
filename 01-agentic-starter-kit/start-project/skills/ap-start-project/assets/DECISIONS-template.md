# Decisions

This is the current ledger of meaningful project choices. It prevents settled questions from being argued again without new evidence.

## Decision fields

Record each decision with:

- date;
- decision;
- reason;
- evidence considered;
- owner or approver;
- whether it is reversible;
- what would justify reopening it;
- link to a detailed decision record when one exists.

If setup finds no prior project decision, record that no project-specific decisions were found during the initial inventory. Do not invent one.
