# Work log

This is the append-only record of work completed in the project. Keep older entries unchanged.

## Entry format

Each entry records:

- date and time;
- who or what acted;
- what changed;
- where it changed;
- why it changed;
- how the result was checked;
- any next action created by the work.

Add the project setup as the first entry. Add one concise entry whenever work changes the project.
