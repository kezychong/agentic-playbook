# Roadmap

This file shows where the project is going. Keep it focused on outcomes and milestones, not a long list of small tasks.

## Intended outcome

Describe the finished business result and the evidence that will prove it is real.

## Milestones

For each milestone, record its outcome, current status, evidence, and any blocker. Use plain status words such as not started, active, blocked, and complete.

## Next action

Name one concrete action that moves the active milestone forward. State who can take it and what input is required.

## Later

Keep deliberately deferred ideas here with the condition that would make them relevant again.

Update this file whenever a milestone moves, a blocker changes, or the next action is completed.
