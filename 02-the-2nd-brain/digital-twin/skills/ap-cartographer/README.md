# Cartographer

Agentic Playbook — **by Kezy** · 0.1.0

Map the kinds of work you actually do into Areas, so later sorting knows where things belong.

## Before you start

Digital Twin finished, with atomic notes in the vault. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Show me the work domains you would detect in a fictional set of notes. Move nothing.

Expected output: A detected-domains list with evidence counts, then one decision per domain (create, subfolder, rename, skip).

## Limits and permissions

No folder is created and no note is moved without the owner's decision on that domain. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Included dependencies

- [Digital Twin](../ap-digital-twin/README.md) — required.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
