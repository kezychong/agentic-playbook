# Digital Twin

Agentic Playbook — **by Kezy** · 0.1.0

A living profile of how you think and decide, built from your own chat history and your answers, with every line traceable to its source.

## Before you start

A Second Brain Setup vault, Claude Code with subagents, and (optionally) a ChatGPT or Claude export placed in `01. Inbox/`. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Read this whole pack, then tell me the phases and what you would create in a fictional test vault. Do not run anything until I say go.

Expected output: The nine phases, the install-state folder it would create, and the first pre-flight checks.

## Limits and permissions

Every phase saves its progress before the next; wiki articles stay drafts until the owner promotes them; nothing personal is invented. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Included dependencies

- [Second Brain Setup](../../../second-brain-setup/README.md) — required.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
