# Dreaming and Recall

Agentic Playbook — **by Kezy** · 0.1.0

Let the brain tidy itself every night and give it a search engine that finds notes by meaning.

## Before you start

Link, Organise and Signal Bots already made and run once by hand. Search needs the open-source GBrain tool; meaning search needs an embeddings key that may cost money. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Show me the nightly jobs and the search setup you would add. Schedule nothing yet.

Expected output: A list of each job (what, when, which bot) and the search install steps, all awaiting approval.

## Limits and permissions

Every timer and every paid key is a separate approval; jobs are listed in AGENTS.md, one line each. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Included dependencies

- [Link, Organise and Signal Bots](../ap-link-organise-signal-bots/README.md) — required.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
