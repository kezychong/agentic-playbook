## Before you start

Link, Organise and Signal Bots running, with Signals in `06. Signals/`. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Show me my top fictional Signals and the notes behind each one.

Expected output: Each Signal with its dated lines, then a request for your watch / drop / done ruling.

## Limits and permissions

Nothing enters the World Model without the owner's yes to that specific belief or decision. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Included dependencies

- [Link, Organise and Signal Bots](../ap-link-organise-signal-bots/README.md) — required.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
