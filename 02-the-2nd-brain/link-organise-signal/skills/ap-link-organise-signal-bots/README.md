# Link, Organise and Signal Bots

Agentic Playbook — **by Kezy** · 0.1.0

Three helper bots and one chain: small linked notes, filing by the Brain Map, and honest counts of what keeps coming up.

## Before you start

The eight-door brain with `_System/brain-map.md`, and Hermes profiles available on the box. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Show me the three bots and the chain you would make for a fictional brain. Make nothing yet.

Expected output: A plan naming each bot, its model weight, its prompt file and the chain order; nothing is created before approval.

## Limits and permissions

Small notes quote their source word for word; a Signal's number is always the count of its dated lines, never an estimate. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
