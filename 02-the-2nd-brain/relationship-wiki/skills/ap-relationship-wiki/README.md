# Relationship Wiki

Agentic Playbook — **by Kezy** · 0.1.0

One private, sourced note per person, so you walk into every meeting already briefed.

## Before you start

A private vault (Second Brain Setup or the eight-door brain). Only material you place in scope is read. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Brief me on fictional client Alex Tan from these two fictional meeting notes.

Expected output: A phone-length brief: who, last contact, open loops both ways, a few sourced points, a suggested opener.

## Limits and permissions

New people are proposed, never added without approval; every fact keeps its source; nothing personal is shared. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Included dependencies

- [Pre-Meeting Brief](../../../../06-ai-sales-team/pre-meeting-brief/README.md) — optional.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
