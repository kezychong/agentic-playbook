# Score Your Brain

**Agentic Playbook — by Kezy**

A fixed, repeatable exam for a second brain: up to 20 questions from your own notes, an answer key kept where the agent cannot read it, a separate grader, and a dated score with its error range. Stage 11 of the [Build Track](../TRACK.md). A local source draft, not an installed or runtime-tested system.

## Included skills
- [Score Your Brain](skills/ap-score-your-brain/README.md): Write a fixed exam from your own notes and score how well your agent remembers, out of 100.

## Setup
1. Read each included skill README and its prerequisites.
2. Keep every skill folder and all its support files together.
3. Review the documented host setup before copying anything into an installation.
4. Use fictional inputs first. Loading a skill does not approve installation, external actions or spending.
