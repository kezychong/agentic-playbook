# Score Your Brain

Agentic Playbook — **by Kezy** · 0.1.0

Turn "my agent does not seem to remember" into a number you can improve.

## Before you start

A second brain the agent searches, Claude Code on the laptop (where the answer key stays), and Hermes on the box. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Help me create a test for a fictional second brain. Write three sample questions and their answer key only.

Expected output: Sample questions in the five types, each with a key for you to check before anything is locked.

## Limits and permissions

The answer key never goes into the brain folder; a grader sees only the key and the answers, never the brain. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Included dependencies

- [Link, Organise and Signal](../../../link-organise-signal/README.md) — optional: the system being measured.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
