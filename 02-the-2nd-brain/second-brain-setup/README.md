# Second Brain Setup

**Agentic Playbook — by Kezy**

This is one package, retaining the supplied grouping and its supporting files. It is a local source draft, not an installed or runtime-tested system.

## Included skills
- [Second Brain Setup](skills/ap-second-brain-setup/README.md): Build or upgrade a PARA vault with receipts.
- [Distill](skills/ap-distill/README.md): Extract lasting ideas into small linked notes.
- [Triage Inbox](skills/ap-triage-inbox/README.md): Classify and route inbox notes with a move ledger.
- [Import Ai Exports](skills/ap-import-ai-exports/README.md): Convert approved AI exports into indexed conversation notes.
- [Weekly Sweep](skills/ap-weekly-sweep/README.md): Review vault health and propose next actions.

## Setup
1. Read each included skill README and its prerequisites.
2. Keep every skill folder and all its support files together.
3. Review the documented host setup before copying anything into an installation.
4. Use fictional inputs first. Loading a skill does not approve installation, external actions or spending.
