# Second Brain Setup

Agentic Playbook — **by Kezy** · 0.1.0

Build or upgrade a PARA vault with receipts.

## Before you start

A dedicated local vault folder, approved scope and the four included helper skills. This is an adapted supplied method, not a live configured profile. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Plan a new Company A vault with one active handbook project.

Expected output: Interview-shaped PARA folders, rules, manifests, note templates and a receipt ledger.

## Limits and permissions

Raw private exports stay outside the vault. Renames, overwrites and schedules require approval. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
