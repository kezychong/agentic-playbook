# Inbox Contract: read before touching anything in this folder

Before you file, move, or tag anything in this folder, decide which of two kinds it is. Everything else follows from that one choice.

## Kind 1: The owner's active work

This is anything the owner is still working on: a plan, a draft, an idea they want to keep building, or a conversation they intend to continue. Signs it's this kind: it talks in first person about what they want to do next, it has a list of next steps, or it reads like a work in progress, not a finished document.

Active work goes to the matching project folder in `02. Projects/`, never into a reference folder. A plan is not research, even if it looks tidy and complete. If no project folder matches yet, ask the owner before creating one.

## Kind 2: Knowledge

This is anything finished: documents, articles, transcripts, closed conversations, reference material. Route it per `_System/VAULT_MANIFEST.md`, which lists exactly where each kind of knowledge belongs.

## When you can't tell

Leave the file right here in the Inbox. Tag it `#status/inbox`. Ask the owner. Never guess, and never route something by default just to clear the folder.

## Sensitive material: never route

Some things must never go into any vault folder: IDs, passports, bank or brokerage statements, contracts that show account numbers, tax documents, or any client's personal details. If you find one of these, leave it exactly where it is, flag it to the owner, and suggest a home for it outside this vault. Do not move it, rename it, or summarize its contents into a note.

## Receipts, always

Every single move out of this folder gets one row in `01. Inbox/WHERE-DID-IT-GO.md`: what moved, what kind it was, where it went, and why. No silent moves, ever. That file is how the owner finds anything that used to be here.

## The imports subfolder

`imports/` is where converted AI conversations land first, before anyone decides if they're worth keeping. See `01. Inbox/imports/README.md` for how that works.
