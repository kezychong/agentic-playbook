# Where Did It Go: Moves Receipt Ledger

This file is the receipt ledger for every file moved out of the Inbox. Whenever an agent or the owner routes something out of `01. Inbox/` (or `01. Inbox/imports/`), it gets one row here: the date it moved, the file's name, what kind of content it was, where it ended up, and one line on why. If the owner ever wonders where something went, this is the first place to check. Never delete a row, even after the file moves again later. Add a new row instead.
