# Projects

A project is a piece of work with a finish line. It's not ongoing; once it's done, it's done.

Each project gets its own folder here. Inside every project folder, keep two files:
- **STATUS.md**: the current truth about where the project stands right now.
- **LOG.md**: a running diary. Add one dated line every time you do work on the project.

When a project is finished, move its whole folder into `05. Archives/`. Don't delete it; it stays searchable there.

The ongoing, never-finished parts of the owner's world (the businesses themselves, and personal life) live in `03. Areas/` instead, not here.
