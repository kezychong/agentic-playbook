# AI Conversations

After the ChatGPT and Claude exports are imported and triaged, the conversations worth keeping land here as individual notes. Each note's top block records which app it came from (`source: chatgpt` or `source: claude`), so no separate subfolders are needed.

The master list of every imported conversation lives at `01. Inbox/imports/INDEX.md`. When a conversation note moves here, update its line in that list so the list always shows where each conversation ended up.

Conversations that turn out to be junk (small talk, dead ends, nothing worth keeping) go to `05. Archives/` instead of living here.

Note: some AI exports include an AI-written memory summary about the owner. Treat it as a first draft only. It isn't verified truth until the owner confirms it themselves.
