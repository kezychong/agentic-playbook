# Weekly Sweep

Agentic Playbook — **by Kezy** · 0.1.0

Review vault health and propose next actions.

## Before you start

An approved vault, note dates/statuses and receipt ledger. This is an adapted supplied method, not a live configured profile. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Review this sample vault and suggest next week’s three distillation candidates.

Expected output: A vault-health report on stale inbox items, orphan notes, routing gaps and decisions due.

## Limits and permissions

Primarily read/report; changes to decision notes require the owner’s confirmed answer. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Included dependencies

- [ap-second-brain-setup](../ap-second-brain-setup/README.md) — required support.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
