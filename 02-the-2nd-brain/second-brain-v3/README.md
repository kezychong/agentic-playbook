# Second Brain V3

**Agentic Playbook — by Kezy**

The eight-door second brain: one plain-text folder on an always-on box, mirrored to the laptop, with a rulebook every agent reads first. It is the base that Capture Bot, Link, Organise and Signal, Connect Your Tools and the Chief of Staff Interview build on. Stages 4 to 6 of the [Build Track](../TRACK.md). A local source draft, not an installed or runtime-tested system.

## Included skills
- [Brain Folder Setup](skills/ap-brain-folder-setup/README.md): Mirror one brain folder between laptop and always-on box, with versioning, and point the agent at it.
- [Brain Installer](skills/ap-brain-installer/README.md): Build the eight doors, the rulebook and the about-me note inside the brain folder.
- [Drop Your Chats](skills/ap-drop-your-chats/README.md): Place an AI chat export whole into Sources so the nightly capture can work through it.
- [Digital Twin Builder](skills/ap-digital-twin-builder/README.md): Interview the owner into five sourced notes, build the Brain Map, and draft replies in their voice.

## Setup
1. Read each included skill README and its prerequisites.
2. Keep every skill folder and all its support files together.
3. Review the documented host setup before copying anything into an installation.
4. Use fictional inputs first. Loading a skill does not approve installation, external actions or spending.
