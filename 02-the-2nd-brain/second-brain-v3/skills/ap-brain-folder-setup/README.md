# Brain Folder Setup

Agentic Playbook — **by Kezy** · 0.1.0

Keep one brain folder matching on your laptop and your always-on box, with file versioning on both ends.

## Before you start

An always-on box already reachable as `my box` (see Server Setup) and a brain folder in your laptop home folder. Runs in Claude Code on the laptop. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Connect to my box and run the brain folder setup pack. Show me the plan first; change nothing yet.

Expected output: A step-by-step plan (Syncthing on both sides, pairing, versioning, Hermes working folder) awaiting approval.

## Limits and permissions

It never makes a second brain folder and never prints a sync key, device ID or address. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Included dependencies

- [Server Setup](../../../../08-setup-guides-tools-connections/server-setup/README.md) — required: the box and its `my box` shortcut.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
