# Brain Installer

Agentic Playbook — **by Kezy** · 0.1.0

Build the inside of a second brain: eight plain folders, a rulebook every agent reads first, and one sourced note about you.

## Before you start

A brain folder the agent works from (ideally mirrored with Brain Folder Setup). Runs in Hermes on the box. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Build my brain in a fictional test folder. Ask your three questions, then show me the build list.

Expected output: Three questions, then a build list (eight doors, AGENTS.md, about-me note) awaiting approval.

## Limits and permissions

It never writes a vault anywhere except the named brain folder and asks before replacing an existing AGENTS.md. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Included dependencies

- [Brain Folder Setup](../ap-brain-folder-setup/README.md) — recommended: mirrors the folder to your laptop.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
