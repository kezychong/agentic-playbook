# Digital Twin Builder

Agentic Playbook — **by Kezy** · 0.1.0

Teach the brain who you are in five sourced notes, then give the night bots a map of where things go.

## Before you start

The eight-door brain with its about-me note. Runs in Hermes on the box. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Start my Digital Twin interview with fictional answers for Company A. Ask only what the brain does not hold.

Expected output: A short summary of what the brain already knows, then one question at a time; notes land in `07. World Model/digital-twin/`.

## Limits and permissions

Every line it writes keeps a `source:` line; a wrong line is fixed only with the owner's stated truth. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Included dependencies

- [Brain Installer](../ap-brain-installer/README.md) — required: the doors and AGENTS.md must exist.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
