# Drop Your Chats

Agentic Playbook — **by Kezy** · 0.1.0

Put a whole AI chat export somewhere safe in the brain, so the nightly capture can work through it a little at a time.

## Before you start

A ChatGPT or Claude export zip holding `conversations.json`, and the eight-door brain. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Here is a fictional export folder. Show me where you would place it and what the progress file would say.

Expected output: The target `08. Sources/chat-exports/<tool>-<date>/` folder and a `0 of N chats done` progress line.

## Limits and permissions

It only places and counts the export; it never reads the chats or writes notes from them. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Included dependencies

- [Capture Bot](../../../capture-bot/README.md) — optional: its nightly chat capture works through the export.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
