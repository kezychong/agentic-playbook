# JARVIS Setup

Agentic Playbook — **by Kezy**

Shape an assistant around confirmed goals, clear decision rights and useful daily outputs. JARVIS Mode adds an optional command-centre interface; its payload is included as unexecuted source, not an installed service.

## Start here

1. Read [setup and permissions](SETUP.md).
2. Follow the [workflow](WORKFLOW.md).
3. Copy the [blank worksheet](templates/workbook.md) into your own draft workspace.
4. Try the [fictional example and expected result](examples/company-a.md).

Suggested sequence: Basic Onboarding → Chief-of-Staff Interview → a local Morning or Attention Brief → optional JARVIS Mode.

## What is included, and what is not

These are adapted supplied methods with original supporting scripts, references and templates retained. Kezy maintains this repackage. No new licence grant is implied; preserve included third-party notices. Start with drafts. Live profile changes, calendar writes, device control, delivery and schedules are separate approved actions. This collection has not been tested against a running host.

Runtime status: **untested**. Local structural checks do not prove that a connector, model, installer or UI automation works. Choose available host/model capabilities at use time. Keep required companion folders when installing an individual skill; its README lists the dependency closure. Optional tools may require separate accounts and fees.
