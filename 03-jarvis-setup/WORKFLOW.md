# Build trust before adding automation

Agentic Playbook — **by Kezy**

## 1. Stage identity and rules

[Basic Onboarding](basic-onboarding/skills/ap-basic-onboarding/SKILL.md) preserves the supplied seven-file convention: IDENTITY, SOUL, AGENTS, USER, TOOLS, MEMORY and HEARTBEAT. These are templates to stage and review. The convention is not a universal host standard. Confirm the selected host/profile, preserve populated files and keep schedules dormant. No real user's boot files are included in this collection.

[Chief-of-Staff Interview](chief-of-staff-interview/skills/ap-chief-of-staff-interview/SKILL.md) adds eight areas: direction, numbers, people/tools, money, life, rhythm, decision rights and trust. Read only explicitly approved notes; ask for what is missing. Record confirmed answers, keep optional sensitive answers private, and propose a merged profile diff. Goals without evidence for a number remain numberless. The detailed source includes resume and read-back procedures.

## 2. Give the assistant a useful daily output

[Morning Brief](morning-brief/skills/ap-morning-brief/SKILL.md) starts with one goal-linked action and its full draft, then a leading metric and up to three additional cards. Its HTML companion is required for the page. Keep a Markdown sidecar so a later reply has a concrete referent. Publish/send/schedule only after the owner approves those exact steps; here.now and Telegram are optional external integrations.

[Attention Brief](attention-brief/skills/ap-attention-brief/SKILL.md) is another route for open commitments and a short morning/evening review. Start with its blank settings. Do not activate both routines blindly: choose the one that fits and avoid duplicate reminders. Failed source reads are visible errors, not a silent “nothing to report.”

[Calendar from Chat](calendar-from-chat/skills/ap-calendar-from-chat/SKILL.md) turns a conversation into an explicit event proposal. Confirm timezone, date, duration, attendees and target calendar before writing; check for duplicates and verify stored state afterward. [Verdict Card](verdict-card/skills/ap-verdict-card/SKILL.md) packages evidence and a choice for the owner. Its copy button copies a response, not permission for unspecified actions.

## 3. Optional JARVIS interface and screen control

[JARVIS Mode](jarvis-mode/skills/ap-jarvis-mode/SKILL.md) includes frontend source and built assets, backend, installer, tests, host patches, configuration examples and third-party notices. All are unexecuted assets. The adapted package is not a verified release: its manifest gates remain false, and the supplied installer therefore refuses installation until new host/device acceptance evidence is recorded by a maintainer. Do not bypass those gates to make a demo appear installed.

Review the source setup sequence, references/install-contract.md and references/device-acceptance.md. Choose explicit main/headless devices, a specific existing profile, and which data boxes may be read. Missing sources should render unavailable states. Review optional patches against the exact supported host revisions before considering any application.

[Macbook Hands](jarvis-mode/skills/ap-macbook-hands/SKILL.md) is the canonical companion. Its support remains under the JARVIS payload; the installer uses a non-discoverable skill-template.md so there is only one public SKILL.md for this ID. macOS screen/accessibility grants and CuaDriver installation require separate approval. Begin with readiness and bounded window state, act using the returned snapshot, then verify. Never type credentials or repeat a failed action blindly.

## 4. Maintain and undo

[Agent Detox](agent-detox/skills/ap-agent-detox/SKILL.md) interviews the owner, inventories instruction files, backs them up, classifies KEEP/MOVE/CUT and shows full proposed replacements. Privacy and money boundaries survive any shortening. Run only against approved files. A successful draft is not evidence of a faster or working runtime; apply only after approval and check a fresh session. Keep restoration instructions with each setup record.
