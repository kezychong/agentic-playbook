# Agent Detox: Install and Use

## What it does

Over time, as you give feedback, your agent may keep adding lines to its instruction files.
Over months they fill up with "do not do this, do not do that". That bloat slows it down and limits its judgment.
This skill interviews you, backs up those files, then cuts them down to the few lines that matter.
You see the before and after, with character counts, and nothing changes until you reply YES.

Think of a new hire with a 40-page rulebook versus a sharp hire with a three-line brief. This gives your agent the three-line brief.

## Who this is for

- You are a business owner who works with an AI agent every day.
- You use the Claude app, the Codex app, or you talk to Hermes in chat.
- You do not need technical skills. Your agent finds the files, backs them up, and does all the editing.

## What you need first

- The Claude app or the Codex app, or your Hermes agent in chat.
- Ten minutes to answer up to six short questions.

## Install

Install it on the agent you want cleaned. If you use Hermes, send it to your Hermes agent in chat, because Hermes keeps its files on your always-on machine. Otherwise, open the Claude app or the Codex app.

Download the zip and say:

```
Install this skill for me from ap-agent-detox-v1.0.0.zip in my Downloads folder, so I can use it everywhere.
```

Talking to Hermes in chat? Attach the zip to that message.
You only do this once per machine. Your agent unpacks it and installs it itself.

## Check it worked

Say:

```
Detox my agent.
```

It should first list your agent's instruction files in a table: size in characters (letters and spaces, not words), number of rules, and number of "do not" lines.
It changes nothing at this point. Next it asks its first interview question.

## How to use it

Say, in your own words:

```
My agent feels slow. Detox my agent.
```

```
Clean up my SOUL.md and HERMES.md. Keep only the lines that matter.
```

```
Do a full prompt audit of my second brain folder.
```

Your agent asks one question at a time and suggests an answer you can accept with "yes".
It shows you the new files in full, then asks: "Apply this? Reply YES or CHANGE <what>."
Afterwards it asks you to open a new chat and check the agent still knows who it is.
Run it again once a month, or whenever your agent feels slow again.

## How to undo

Every file is backed up before anything changes. Nothing is deleted.
To put your old files back, say:

```
Restore my agent files from the detox backup.
```

To remove the skill itself, say:

```
Remove the ap-agent-detox skill.
```
