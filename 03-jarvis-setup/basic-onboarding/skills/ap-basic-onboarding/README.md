# Basic Onboarding

Agentic Playbook — **by Kezy** · 0.1.0

Stage seven agent boot files from confirmed answers.

## Before you start

A selected Hermes host/profile and a separate draft staging folder. This is an adapted supplied method, not a live configured profile. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Stage a blank seven-file onboarding proposal for a fictional assistant.

Expected output: IDENTITY, SOUL, AGENTS, USER, TOOLS, MEMORY and dormant HEARTBEAT templates.

## Limits and permissions

Never execute on load; review the staged diff and back up before any live profile change. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Included dependencies

No other packaged skill is required.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
