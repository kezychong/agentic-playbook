# Calendar from Chat: Install and Use

Collection: Agentic Playbook — by Kezy. Use the included canonical skill folder.

Turn a message into a checked calendar change. Your agent books, moves, cancels, or blocks time for you. It checks dates and clashes, then reads back what your calendar actually saved.

Works in Claude Code and in Codex.

## What you need first

- The Claude app or the Codex app.
- The downloaded `ap-calendar-from-chat.zip`.
- A calendar account you can connect when your agent asks.

Your agent handles installation and checks calendar access.
It tells you if your account needs sign-in.

## Install

Say:

> Install the skill in my downloaded ap-calendar-from-chat.zip so I can use it in every project.

Your agent unpacks it and installs any supported requirements itself.
It prints where the skill was installed.

## Check it worked

Say:

> Set up ap-calendar-from-chat and check access. Do not create any events yet.

Your agent asks about your calendar, timezone, meeting length, meeting link, and attendee preference.
It asks one question at a time and saves your answers.
It prints the settings file path and reports whether calendar access worked.
This check does not prove that a booking has succeeded.

## How to use it

1. Type or forward your meeting message to your agent.
2. Say what you want, such as "Book this supplier visit for 90 minutes."
3. Read the weekday, full date, time, and timezone it shows before writing.
4. Answer if the date is unclear or an existing event needs identifying.
5. If there is a clash, choose one of the two checked alternatives.
6. Read the final saved details, including attendees and the meeting place or link.
7. Send any announcement draft yourself when you are ready.

For several changes, name each event and its new date.
For repeating events, say whether to change one date, future dates, or the whole series.
Your agent reports each completed change and anything still unresolved.

## What it will NOT do

- Send invitations or announcements.
- Delete events it did not create without your explicit "yes, delete".
- Guess an unclear date or quietly double-book you.
- Claim success without checking what your calendar saved.
- Book anything during the setup-only check.
