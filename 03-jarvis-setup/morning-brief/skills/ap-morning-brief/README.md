# Morning Brief

Agentic Playbook — **by Kezy** · 0.1.0

Draft a goal-linked morning brief and review cards.

## Before you start

Approved goals and sources; ap-html-output for the page. Telegram and publishing are optional. This is an adapted supplied method, not a live configured profile. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Draft a local morning brief from Company A’s sample goal; do not send or schedule.

Expected output: A local HTML page and Markdown sidecar with one complete draft action, leading metric and up to three more cards.

## Limits and permissions

Missing numbers say “not counted yet”. Publication, delivery and schedules are separate approvals. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
