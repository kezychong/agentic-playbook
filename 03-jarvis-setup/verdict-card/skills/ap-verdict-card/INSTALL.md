# Verdict Card: Install & Use

Collection: Agentic Playbook — by Kezy. Use the included canonical skill folder.

This skill puts a decision and its full explanation on one page. You choose an answer and copy it back. Your agent saves your words and remembers what you decided.

Works in Claude Code and in Codex.

## What you need first
- Your agent app.
- The downloaded `ap-verdict-card.zip`.
- An agent that can save files for permanent records.

## Install
Say this to your agent:

```text
Install the skill in my downloaded ap-verdict-card.zip so I can use it in every project.
```

Your agent handles installation and any requirements. It explains any unavailable ability in plain words.

## Check it worked
Say: "Use ap-verdict-card to help me choose between two launch dates."
Your agent asks where to save cards and answers, one question at a time.
It then creates the card and gives you a clickable link.

## How to use it
1. Tell your agent which decision you need help reviewing.
2. Read the full explanation on the card.
3. Choose an option and add a note if you want.
4. Press "Copy my verdicts" and paste the block into your agent chat.
5. Your agent saves your exact answer and links the decision record.
6. Any unanswered choices stay listed. An expired choice returns once in the next brief.

If copying is blocked, select and copy the visible answer box.
If pages are unavailable, your agent shows the same numbered cards in chat.
It explains the reply format and tells you whether anything was saved.

## What it will NOT do
- Choose for you or treat silence as approval.
- Send or publish your card.
- Rewrite an earlier decision.
- Claim a result was checked when it was "assumed, not checked".
