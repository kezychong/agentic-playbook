# Verdict Card

Agentic Playbook — **by Kezy** · 0.1.0

Create an evidence-based decision card for review.

## Before you start

A real decision, available evidence and blank settings. This is an adapted supplied method, not a live configured profile. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Compare two fictional handbook launch dates using only these constraints.

Expected output: An HTML/Markdown decision card with recommendation, uncertainty and a copyable response.

## Limits and permissions

A card records a decision; it does not authorize the proposed external action. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Included dependencies

No other packaged skill is required.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
