# Build a Loop

Agentic Playbook — **by Kezy** · 0.1.0

A prompt does the work once. A loop does the work, checks it against your written standard, and gets stricter every time you correct it.

## Before you start

One output you make again and again, and a few real examples you accepted and rejected. Works in any skill-capable coding agent; [any-agent-prompt.md](references/any-agent-prompt.md) runs the same interview without installing. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Help me build a loop for a fictional weekly client report.

Expected output: Five stages, one at a time: find the loop, break it into stages, draft the rubric, set up worker and checker, make it compound. Ends with `loop-spec.md` and `rubric.md`.

## Limits and permissions

The worker never grades its own work; only work that passes the rubric reaches the owner. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Included dependencies

No other packaged skill is required.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
