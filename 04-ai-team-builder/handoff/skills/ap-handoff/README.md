# Handoff

Agentic Playbook — **by Kezy** · 0.1.0

End a long session without losing the thread: one file a stranger could pick up and continue.

## Before you start

A working session with real state to hand on. No vault or account needed. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Write a handoff for this fictional session: two tasks done, one blocked, one untested.

Expected output: One short document in a temp folder: goal, done / in progress / blocked, verified versus assumed, next steps, key paths.

## Limits and permissions

It strips keys, passwords and tokens, points to files instead of copying them, and labels anything untested as assumed. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Included dependencies

No other packaged skill is required.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
