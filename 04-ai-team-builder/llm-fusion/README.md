# LLM Fusion

**Agentic Playbook — by Kezy**

When one AI answer is too easy to trust: ask several different models the same thing, sealed from each other, then judge their answers blind. One skill for decisions, one for builds. Uses whatever model routes your host already has; no extra product required. A local source draft, not an installed or runtime-tested system.

## Included skills
- [Fusion Council](skills/ap-fusion-council/README.md): Put one hard question to several different models separately, hide who said what, then judge one decision memo.
- [Fusion Build](skills/ap-fusion-build/README.md): Have several models plan the same build separately, merge the strongest plan, then build and audit it.

## Setup
1. Read each included skill README and its prerequisites.
2. Keep every skill folder and all its support files together.
3. Review the documented host setup before copying anything into an installation.
4. Use fictional inputs first. Loading a skill does not approve installation, external actions or spending.

[Host setup guide](../../08-setup-guides-tools-connections/manual-setup.md)
