# Fusion Build

Agentic Playbook — **by Kezy** · 0.1.0

Three sealed plans, one merged plan, one build, one independent audit.

## Before you start

Access to at least three different model families and a separate working copy to build in. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Run a fusion build on a fictional landing-page change. Plans only; build nothing.

Expected output: Three anonymised plans and one merged plan with the origin of each step, awaiting approval to build.

## Limits and permissions

The builder works in a separate copy; the auditor is a different seat from the builder. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Included dependencies

- [Fusion Council](../ap-fusion-council/README.md) — sibling skill for decisions.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
