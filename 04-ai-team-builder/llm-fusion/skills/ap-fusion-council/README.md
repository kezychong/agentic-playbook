# Fusion Council

Agentic Playbook — **by Kezy** · 0.1.0

Several models answer alone, names hidden, and one judge writes the decision memo.

## Before you start

Access to at least three different model families in your host (CLIs, subagents or API routes you already have). Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Run a fusion council on this fictional decision: raise prices 10% or add a premium tier? Show me the brief and seats first.

Expected output: A brief and seat list for approval, then a decision memo with agreements, splits, surviving points and a receipt.

## Limits and permissions

Seats never see each other's answers; the judge never sees model names. Paid model calls need approval. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Included dependencies

No other packaged skill is required.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
