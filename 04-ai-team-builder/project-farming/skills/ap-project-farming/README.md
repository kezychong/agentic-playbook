# Project Farming

Agentic Playbook — **by Kezy** · 0.1.0

Find the plan, find the reality, report the gap: a score out of 10, ranked gaps with evidence, quick wins and structural fixes.

## Before you start

A project with some written intent (a roadmap, brief, README promises or task board) and read access to what was actually built. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Review this fictional project folder against its README and tell me what is actually built.

Expected output: A verdict line (X/10 and why), gaps ranked by impact with evidence, quick wins versus structural changes, and a path back to faithful.

## Limits and permissions

It assesses; it does not fix anything unless the owner asks for the quick wins. A review that found nothing checked nothing. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
