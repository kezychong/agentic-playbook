# Brand Strategy

**Agentic Playbook — by Kezy**

Package version **0.1.0**. This public-safe package groups three complementary skills for strategy, foundation building and evidence review. It is a local source draft, not an installed or runtime-tested system.

## Included skills
- [Brand Strategist](skills/ap-brand-strategist/README.md): Develop evidence-led brand strategy and activation plans.
- [Brand Build](skills/ap-brand-build/README.md): Build a brand foundation from evidence and explicit decisions.
- [Brand Audit](skills/ap-brand-audit/README.md): Audit public brand claims against dated evidence.

Use **Brand Build** for a new or incomplete foundation, **Brand Strategist** for a strategic problem or go-to-market decision, and **Brand Audit** to test claims made by an existing brand.

## Setup
1. Read the relevant skill README and prerequisites.
2. Keep each skill folder and all of its files together.
3. Review the documented host setup before copying anything into an installation.
4. Start with a fictional brand. Loading a skill does not approve installation, external research, account access, publication or spending.
