# Brand Audit

Agentic Playbook — **by Kezy**

Audit public brand claims against dated evidence.

## Prerequisites

The brand identity, exact public surfaces to review, permitted evidence sources, and a user-selected workspace for the draft register.

## Try it

> Audit the claims in this fictional Company A landing page. Use only the supplied evidence pack and do not rewrite the live page.

## Expected output

A claim-to-proof register, evidence gaps, cross-surface inconsistencies, public-use constraints and draft remediation options.

## Install and use

Read [the complete method](SKILL.md) and [local setup](INSTALL.md). Copy the whole folder. Run a harmless fictional sample before allowing real or confidential data.

## Limits

Runtime status: **untested**. The audit is not legal, regulatory or certification advice. It never edits live assets or publishes. Missing proof remains a finding; it is not filled with plausible language.
