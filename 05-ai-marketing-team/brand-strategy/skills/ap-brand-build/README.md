# Brand Build

Agentic Playbook — **by Kezy**

Build a brand foundation from evidence and explicit decisions.

## Prerequisites

A new or incomplete brand, a responsible decision-maker, basic business context, and a workspace where drafts may be saved.

## Try it

> Build the first foundation draft for fictional Company A. Use only this short founder brief, mark every assumption, and stop before any public copy.

## Expected output

A workbench, evidence record and seven-part brand foundation covering audience situation, position, promise, proof, personality, relationship and recognisable expression.

## Install and use

Read [the complete method](SKILL.md) and [local setup](INSTALL.md). Copy the whole folder. Run a harmless fictional sample before allowing real or confidential data.

## Limits

Runtime status: **untested**. A plausible draft is not a decision or proof. No invented research, quotes, results, design assets, typeface rights or colour values. No automatic publication or changes to live brand materials.
