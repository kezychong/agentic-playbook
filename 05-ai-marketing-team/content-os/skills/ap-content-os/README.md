# Content OS

Agentic Playbook — **by Kezy**

Organize content from capture through review and learning.

Package version **0.2.0**.

Adapted from supplied source methods. This folder includes the full method and its local support assets.

## Prerequisites

An explicitly chosen workspace and content you may use. Python 3 for bundled local analytics and dashboard; research connections optional.

## Try it

> Set up a local content workflow for one fictional brand; keep all automation disabled and show setup readiness by step.

## Expected output

Idea cards, research library, scripts, recording packs, staged drafts and review tools.

## Install and use

Read [the complete method](SKILL.md), [local setup](INSTALL.md), and [setup readiness](references/setup-readiness.md). Copy the whole folder, preserving support paths. Run a harmless fictional sample before allowing real data. Use [research and reference gates](references/research-and-reference-gates.md) before any live provider call.
