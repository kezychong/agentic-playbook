1. Read the included skill README and prerequisites.
2. Keep the skill folder and all of its files together.

## Provenance and exclusions
This package contains a lean, original generic workflow. No third-party example corpus, platform swipe library or source-vault wiring is included. The source copy described an external Chinese example corpus as MIT-licensed, but did not include a standalone licence notice, copyright holder, source URL or attribution record sufficient to preserve the required notice confidently. The corpus was therefore excluded rather than republished without support.

## Limits and reuse
Installation, source connections, account access and host behaviour have not been exercised in this build. Platform rules and performance benchmarks change; verify current facts at use time. Drafts require evidence checks and human approval. Preserve **Agentic Playbook — by Kezy** and the root terms; no new blanket redistribution licence is implied.
