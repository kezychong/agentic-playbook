# Content Plan

Agentic Playbook — **by Kezy**

Plan evidence-led organic content batches from business goals.

This is a lean original workflow. It does not bundle a third-party example corpus or platform swipe library.

## Prerequisites

A brand, business objective, planning window, production capacity, intended audience, permitted evidence, platforms and language.

## Try it

> Plan a four-week organic content batch for fictional Company A using only this brief and evidence pack. Keep every post as a draft.

## Expected output

A source register, audience-and-action diagnosis, message options, capacity-based allocation, approved batch brief, content map, draft briefs and review plan.

## Install and use

Read [the complete method](SKILL.md) and [local setup](INSTALL.md). Copy the whole folder. Run a harmless fictional sample before allowing real or confidential data.

## Limits

Runtime status: **untested**. No performance or conversion guarantee. Platform rules must be checked at use time. The skill does not publish, schedule, connect accounts or treat strategy documents as customer evidence.
