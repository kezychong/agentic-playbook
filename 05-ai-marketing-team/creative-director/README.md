# Creative Director

**Agentic Playbook — by Kezy**

An original, public-safe package for planning and reviewing evidence-led video work. Five focused skills cover direction, short video, motion graphics, narrated video and footage assembly without copying a private agent, personal setup or proprietary source pack. Review uses the host's review-capable vision tool; media generators only make assets and never review their own output.

This is a local source draft. It is not installed or runtime-tested. It does not connect accounts, call paid tools, publish, post, send or change live systems.

## Included skills

- [Creative Direction](skills/ap-creative-direction/README.md) — turn an objective and permitted evidence into a reviewable video plan.
- [Short Video Production](skills/ap-short-video-production/README.md) — prepare short talking-camera, reaction and demonstration drafts.
- [Motion Graphics Production](skills/ap-motion-graphics-production/README.md) — brief and review programmatic motion work without assuming a renderer.
- [Narrated Video Production](skills/ap-narrated-video-production/README.md) — plan narration-led explainers, slide-led videos and recorded teaching sessions.
- [Footage Story Assembly](skills/ap-footage-story-assembly/README.md) — shape permitted footage into montages, highlights and evidence-led stories.

The grouping is deliberate. Shared planning and truth checks live in Creative Direction. Format-specific craft stays in the other four skills. Narration uses permitted human recordings only.

## Start safely

1. Read [START-HERE.md](START-HERE.md).
2. Begin with Creative Direction and a fictional brief.
3. Select one production skill only after the video canvas is approved.
4. Keep real footage and filled working documents outside this public source folder.
5. Stop at a local review draft. Publishing, sending, spending and live account changes are separate actions requiring explicit approval.

## Optional companions

- [Content Plan](../content-plan/README.md) can supply an approved content brief.
- [Content OS](../content-os/README.md) can track draft status and learning.
- [Edit Pipeline](../edit-pipeline/README.md) can handle a separately approved talking-camera edit. For a clean-up-only job, its approved cut list can serve as the production plan; no cut starts before that approval.

These are optional products. If they are absent, report the limitation and use this package's manual path.

## Included checks

Creative Direction includes a dependency-free plan checker and fictional fixtures. It checks structure, evidence references, consent, review state and disabled external actions. Passing it does not prove a video is accurate, lawful, accessible, good or ready to publish.

## Limits and reuse

This package was written as an original generic workflow from common production practices. No private or sensitive source material was intentionally included. Named tools are optional examples only; availability, licence, cost and host compatibility must be checked at use time.

No renderer, transcription engine, media generator, production workflow, account connection or host integration was exercised as part of this package build. The plan checker's offline tests are the only executed part. Human review remains required for facts, claims, rights, consent, accessibility, final playback and every external action. Preserve the collection terms and required credit.
