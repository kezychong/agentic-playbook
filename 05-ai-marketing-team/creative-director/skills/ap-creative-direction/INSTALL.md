# Local setup: Creative Direction

Agentic Playbook — by Kezy

This is a local, uninstalled skill folder, version 0.1.1.

1. Read the complete `SKILL.md` and the collection [manual setup guide](../../../../08-setup-guides-tools-connections/manual-setup.md).
2. With approval to change the host, copy the complete `ap-creative-direction/` folder to the host's documented skill location. Back up an existing same-ID folder rather than overwriting it.
3. Keep filled canvases, evidence ledgers, footage and exports in a separate private workspace.
4. Confirm skill discovery in a fresh session and run the fictional example.
5. Optionally run `PYTHONDONTWRITEBYTECODE=1 python3 scripts/test_check_video_plan.py`. This uses only Python's standard library, keeps temporary fixtures outside the package and suppresses local bytecode cache files.
6. To update or remove, change only this installed folder with approval. Preserve private projects separately.

No installation, account connection, paid call, external action or host compatibility was tested by preparing this package.
