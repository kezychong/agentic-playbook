# Local setup: Footage Story Assembly

Agentic Playbook — by Kezy

This is a local, uninstalled skill folder, version 0.1.1.

1. Read `SKILL.md` and the collection [manual setup guide](../../../../08-setup-guides-tools-connections/manual-setup.md).
2. With approval, copy the whole folder to the host's documented skill location. Preserve an existing same-ID version.
3. Keep recordings, transcripts, identities, consent records, cut lists and renders in a separate private workspace.
4. Test discovery with fictional clips and a planning-only request.
5. Transcription and editing tools are separate prerequisites. Verify licence, privacy, cost and host support before use. Installation, paid calls and external actions need explicit approval.
6. Removal changes only this skill folder. It does not delete footage, private records, tools, accounts or live media.

No installation, media tool or host compatibility was tested by preparing this package.
