# Local setup: Motion Graphics Production

Agentic Playbook — by Kezy

This is a local, uninstalled skill folder, version 0.1.0.

1. Read `SKILL.md` and the collection [manual setup guide](../../../../08-setup-guides-tools-connections/manual-setup.md).
2. With approval, copy the whole folder to the host's documented skill location. Preserve an existing same-ID version.
3. Keep brand assets, footage, filled ledgers, projects and renders in a separate private workspace.
4. Test discovery with a fictional renderer-neutral brief before using a real project.
5. A renderer is optional and separate. Inspect an existing project's local instructions first. Installing packages, changing versions, using cloud rendering or making paid media calls requires explicit approval.
6. Removal changes only this skill folder. It does not remove renderers, packages, private projects or accounts.

No toolchain or host compatibility was tested by preparing this package.
