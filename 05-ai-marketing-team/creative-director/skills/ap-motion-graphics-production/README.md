# Motion Graphics Production

Agentic Playbook — **by Kezy**

Brief and review evidence-led motion graphics without assuming a renderer.

## Prerequisites

An approved video canvas, truth block, brand decisions, output specification, permitted assets, rights record, local renderer decision and named reviewers.

## Try it

> Create a timed storyboard and a renderer-neutral build brief for a fictional 20-second product diagram. Do not install tools, generate paid media or publish.

## Expected output

A route decision, truth block, timed storyboard, asset ledger, representative-scene plan, render QA plan and review handoff.

## Limits

Runtime status: untested source draft. No renderer, package, media generator, cloud service or account was exercised. A successful source or syntax check does not prove a video rendered correctly.
