# Local setup: Narrated Video Production

Agentic Playbook — by Kezy

This is a local, uninstalled skill folder, version 0.1.0.

1. Read `SKILL.md` and the collection [manual setup guide](../../../../08-setup-guides-tools-connections/manual-setup.md).
2. With approval, copy the complete folder to the host's documented skill location. Preserve an existing same-ID version.
3. Keep scripts, narration, slides, footage and renders in a separate private workspace.
4. Test discovery with a fictional script-and-still-plan request first.
5. Narration, transcription, slide capture and rendering tools are separate prerequisites. Verify rights, privacy, licence, cost and host support before use. Installing, spending and external actions need explicit approval.
6. Removal changes only this skill folder. It does not delete private media, tools, accounts or live videos.

No installation, renderer or host compatibility was tested by preparing this package.
