# Narrated Video Production

Agentic Playbook — **by Kezy**

Plan narration-led explainers and teaching videos with staged review gates.

## Prerequisites

One learning outcome, approved sources, an approved script path, permitted human narration, visual assets, rights and consent, target format and reviewers.

## Try it

> Create a script review and static scene plan for a fictional three-minute feature walkthrough. Use human-recorded narration as the future input. Do not render or publish.

## Expected output

A teaching contract, script, scene-by-scene still plan, timing method, production brief, mechanical QA plan, playback table and hold list.

## Limits

Runtime status: untested source draft. No narration, slide, transcription, render or publishing tool was exercised. Narration uses permitted human recordings; synthetic identity processing is not included.
