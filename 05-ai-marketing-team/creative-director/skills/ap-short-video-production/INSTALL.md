# Local setup: Short Video Production

Agentic Playbook — by Kezy

This is a local, uninstalled skill folder, version 0.1.1.

1. Read `SKILL.md` and the collection [manual setup guide](../../../../08-setup-guides-tools-connections/manual-setup.md).
2. With approval to change the host, copy the complete folder to its documented skill location. Preserve an existing same-ID version.
3. Keep footage, transcripts, filled evidence ledgers and exports in a separate private workspace.
4. Confirm discovery in a fresh session and run only a fictional planning example first.
5. Any editor, transcription engine, caption tool or media generator is a separate prerequisite. Verify its licence, privacy, cost and current host support before proposing use. Installing or spending needs explicit approval.
6. Removal changes only this skill folder. It does not remove private project files, tools, accounts or scheduled work.

No installation or host compatibility was tested by preparing this package.
