# Short Video Production

Agentic Playbook — **by Kezy**

Prepare truthful short-video drafts with evidence and review gates.

## Prerequisites

An approved message or video canvas, permitted source footage, a claim ledger, known rights and consent, target format and a local working folder.

## Try it

> Build a cut plan and visual beat map for a fictional 45-second talking-camera transcript. Use only the supplied fictional evidence. Stop at a local review draft.

## Expected output

A source inventory, transcript status, cut list, visual beat map, caption plan, review draft and hold list.

## Limits

Runtime status: untested source draft. No editor, transcriber, renderer, media generator, account connection or publication was tested. This skill does not post, send or spend.
