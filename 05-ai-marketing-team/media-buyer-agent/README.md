# Media Buyer Agent

**Agentic Playbook — by Kezy**

A paid-media operator agent with the guardrails written in before it ever sees spend: read-only first, decisions by ad-set or ad-level cost per result (never blended account averages), paused-first test launches, tracker and creative hygiene, and weekly reports that separate what was recommended from what was done. Every platform write, even a paused draft, needs explicit approval. Start with the [onboarding pack](media-buyer-onboarding-pack/START-HERE.md), then read the [distribution templates](media-buyer-distribution/README.md). A local source draft, not an installed or runtime-tested system.

## Included skills
- [Approval-Gated Actions](skills/ap-approval-gated-actions/README.md): Safety gate for all Meta writes, live spend, status, budget, tracker, and launch changes.
- [Basic Ad-Buying Recipe](skills/ap-basic-ad-buying-recipe/README.md): Core two-campaign paid-media recipe: testing, scaling, and test/keep/pause/kill/scale decisions.
- [Weekly Report Writer](skills/ap-weekly-report-writer/README.md): Owner-facing weekly report writer for spend, results, decisions, creative learnings, and next actions.
- [Creative Quality Gate](skills/ap-creative-quality-gate/README.md): Creative QA gate for mobile legibility, layout, claims, aspect ratio, and launch readiness.
- [Paused Launch Planner](skills/ap-paused-launch-planner/README.md): Paused-first launch planner for testing concepts and scaling winners without live activation.
- [Meta Account Readiness](skills/ap-meta-account-readiness/README.md): Read-only account readiness check for Meta connector access, scope, account selection, and tool availability.
- [Daily Performance Review](skills/ap-daily-performance-review/README.md): Daily review workflow that turns platform numbers into keep, pause, kill, graduate, scale, and watch recommendations.
- [Tracker Sheet Review](skills/ap-tracker-sheet-review/README.md): Tracker/sheet workflow for row review, frozen-row protection, explicit ranges, and approval-gated row changes.
- [Tracker and Creative JSON Update](skills/ap-tracker-and-creative-json-update/README.md): Approval-gated template for updating tracker rows and each creative's JSON data without client-specific fields.

## Setup
1. Read each included skill README and its prerequisites.
2. Keep every skill folder and all its support files together.
3. Review the documented host setup before copying anything into an installation.
4. Use fictional inputs first. Loading a skill does not approve installation, external actions or spending.
