# Connect Meta - Route 1

Default route: Meta hosted Ads connector.

Endpoint:
https://mcp.facebook.com/ads

## Steps
1. Open the AI client's connector or MCP settings.
2. Add the endpoint above or choose the official Meta Ads connector.
3. Complete Meta login in the browser.
4. Choose the ad account and Page.
5. Start with read-only scope.
6. Ask the agent to list visible ad accounts.
7. Ask for a tiny read-only ad-set insight sample.

Stop if the login is not on a Meta or Facebook-owned domain.
