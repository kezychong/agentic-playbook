# First Week Runbook

Use this for the first seven days after install.

## Day 0 - Setup
- Install the profile from the local folder.
- Confirm Hermes Chief of Staff / Codex already works on this device.
- Connect Meta read-only.
- Fill offer, primary result type, target cost per result, and budget.
- Run QA-SCENARIOS.md.

## Day 1 - Baseline
- Use ap-meta-account-readiness.
- Pull visible campaigns, ad sets, ads, and a small insight sample.
- Use ap-weekly-report-writer for a baseline note.

## Days 2-3 - Review
- Use ap-daily-performance-review.
- Put items into keep, pause recommended, kill recommended, graduate recommended, scale recommended, or watch.
- Use ap-tracker-and-creative-json-update to prepare a dry-run packet when tracker rows or creative JSON records need changes.
- Execute nothing without approval.

## Days 4-5 - Creative
- Use ap-creative-quality-gate on replacement ideas.
- Use ap-paused-launch-planner for draft testing concepts.
- Do not write paused drafts into Meta unless the owner approves that platform write.

## Days 6-7 - Owner Review
- Use ap-weekly-report-writer.
- Decide next test concepts.
- Confirm whether scope should stay read-only or move to draft-building only.
