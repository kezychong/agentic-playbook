# Weekly Report Writer

Use for weekly or date-range summaries.

## Inputs
- Exact start and end dates.
- Account label.
- Spend, results, cost per result, CTR, CPM, frequency, and notes.
- Actions recommended and actions executed.
- Creative QA learnings.
- Tracker gaps.

## Structure
1. Date range and source.
2. Executive summary.
3. Spend and result table.
4. Winners.
5. Losers or watch items.
6. Creative learnings.
7. Recommended actions.
8. Approval needed.
9. Setup gaps.

## Rules
- No raw platform dumps.
- No account-level cost-per-result decisions.
- Every number gets a date range and source.
- Separate recommended from executed.
