# Local setup: Presentation Builder

Agentic Playbook — by Kezy

This is a local, uninstalled skill folder, version 0.2.0.

1. Choose a supported host and consult the collection [setup guides](../../../../08-setup-guides-tools-connections/README.md) for its documented skill location.
2. With approval to change host configuration, copy the entire `ap-presentation-builder/` folder. Keep `SKILL.md`, references, assets, evals, and the optional checker together. Back up an existing same-ID version instead of overwriting it.
3. Refresh skill discovery using the host's documented method, confirm `ap-presentation-builder` is visible, and try the fictional example in the package README.
4. Install optional checker dependencies only after reviewing permissions and compatibility. Opening this folder runs nothing.
5. To update, compare the installed version and local edits before replacing it. To remove, disable discovery and remove only this installed folder with approval. Keep authored decks separately.

Prerequisites: source material, intended audience, and outcome. Use a browser for visual review. The optional checker requires Python, Pillow, Playwright, and a compatible browser.

## Use boundary

Use only an approved workspace and material. Loading this folder does not install tools, connect accounts, start services, create schedules, or publish a deck. Keep credentials in secure local setup. State missing tools and unperformed checks plainly.
