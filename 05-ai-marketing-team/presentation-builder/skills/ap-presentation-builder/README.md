# Presentation Builder

Agentic Playbook — **by Kezy**

Build clear browser-based decks from supplied evidence. Version 0.2.0.

## Prerequisites

Source material, intended audience, and outcome. Use a browser for visual review. The optional checker requires Python, Pillow, Playwright, and a compatible browser.

## Try it

> Interview me one question at a time, then turn this workshop idea into an Editorial Ink deck. Show me the outline before building.

## Expected output

An HTML deck, approved story outline, embedded or approved project-relative assets, and optional browser-check artifacts.

## Install and use

Read [the complete method](SKILL.md) and [local setup](INSTALL.md). Copy the whole folder so its references, assets, and optional checker remain together. Run a harmless fictional sample before allowing real data.

## Limits

The skill requires human fact-checking and final review. Browser rendering and optional dependencies vary by host. No performance, conversion, compatibility, or integration guarantee is made. Loading this package does not install software, connect accounts, publish, spend, delete, or change a live system. Keep credentials in secure local setup, never chat or deck files.
