# Install — Retargeting Ads Architect

## Not sure how to install this? Just ask your AI

This skill is a portable folder intended for a compatible host; discovery is untested. If you're not sure how to get it installed, don't fuss with the steps below yourself: just paste the folder location to your AI and say **"install this skill for me"**, and it will handle it.

## Folder placement

Use the documented host location confirmed by the collection setup guide.

## How to invoke

Once it's in place, just describe what you want in plain language and Claude Code will load it automatically. You do not need to remember a command. Any of these will trigger it:

- "My organic content is getting views but my cold ads are expensive. What should I run?"
- "Set up retargeting ads for my funnel."
- "Retarget everyone who watched my videos."
- "Create custom audiences for my funnel."
- "People are watching my videos but not booking — help me advertise to them."

If you want to force it, you can also say: "Use the retargeting-ads-core-funnel skill."

## What you'll need on hand

- Your **landing page**, **booking page**, and **thank-you page** URLs.
- A Meta (Facebook) ad account with the Facebook pixel already installed on your pages, and your organic Instagram/Facebook account connected.
- A description of your ideal customer and your offer (the skill will help you write these into two small files if you don't have them yet).

## Optional — direct account access

If you have a currently verified compatible Meta Ads connector set up in Claude, the skill can create your audiences and campaigns for you (it will always confirm each one first). If you don't, it walks you through Meta Ads Manager step by step — you can screenshot any screen and ask.
