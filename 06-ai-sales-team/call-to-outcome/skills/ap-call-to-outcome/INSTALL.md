# Call to Outcome: Install and Use

Included locally: use this complete skill folder; no external download is required.

Give your agent a call transcript or recording and name the document you need.
It writes the actual proposal, action plan, follow-up email, decision memo, procedure, project brief, or reusable skill.
Each document shows what happens next and keeps evidence from the call.

Works in Claude Code and in Codex.

## What you need first
- The Claude app or the Codex app, with an agent that can save files.
- This downloaded skill zip.
- A call transcript or recording when you want to make an outcome.

Your agent handles setup. A skill is a recipe your agent follows.
For recordings, it checks the transcription tool and sets it up when supported.
If setup is unavailable, it explains the limit and asks for an existing transcript.

## Install
Attach this zip in your agent's app and say:

> Install this skill for me so I can use it in my projects.

Your agent unpacks it, checks the files, and confirms whether installation worked.

## Check it worked
Tell your agent:

> Use ap-call-to-outcome and help me set it up.

It asks which outcomes you need, one question at a time.
It saves your choices and confirms where your settings live.
An installation claim without that check is "assumed, not checked".

## How to use it
1. Give your agent the call recording, transcript file, or pasted transcript.
2. Say: "Turn this call into a proposal and an action plan."
3. Answer any question about missing facts or the people receiving the work.
4. Open the finished files using the links your agent gives you.
5. Review any fields marked "Needs confirmation" before using the draft.
6. For another outcome, say: "Now make the follow-up email from the same call."

Your first run sets your usual outcomes, recipients, voice, output folder, and transcription preference.
Later runs read those settings. Tell your agent when you want to change them.

## What it will NOT do
- Send anything, publish anything, or add tasks to your live board.
- Replace your requested document with meeting notes.
- Invent a price, promise, owner, or deadline.
- Change your original recording.
- Claim an unchecked fact is confirmed.
