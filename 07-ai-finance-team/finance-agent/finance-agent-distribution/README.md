# Finance Agent distribution templates

Agentic Playbook — **by Kezy**

SOUL.md defines identity; AGENTS.md and HERMES.md are identical operating-manual templates.
config.yaml and distribution.yaml describe intended configuration, not a verified runtime schema.
.env.EXAMPLE contains only commented key names. mcp.json contains no active servers.

Fill placeholders in a separate staged copy after the onboarding interview. Never load these
blank templates as a live profile. Review the filled copy and exact destination before approving
installation; preserve existing profile files. Do not overwrite another agent's identity.

The two canonical skills live outside this template folder:
[Monthly close](../skills/ap-monthly-close/SKILL.md) and
[Weekly money report](../skills/ap-weekly-money-report/SKILL.md).
Copy their complete folders into the chosen host's documented skill location. Nothing autostarts.

Begin with [onboarding](../finance-agent-onboarding-pack/START-HERE.md).
Read-only reporting readiness never authorizes production writes. All runtime setup is untested.
