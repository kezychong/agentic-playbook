# Add a Key

**Agentic Playbook — by Kezy**

Every service key goes one road: from your clipboard, through a pipe, into one locked file on the box. It never appears in a chat, a note or a screenshot, and you only ever see key names. Stage 8 of the [Build Track](../../02-the-2nd-brain/TRACK.md). A local source draft, not an installed or runtime-tested system.

## Included skills
- [Add a Key](skills/ap-add-a-key/README.md): Move a service key from the clipboard into the box's locked file without it ever appearing in chat, and keep a names-only key list.

## Setup
1. Read each included skill README and its prerequisites.
2. Keep every skill folder and all its support files together.
3. Review the documented host setup before copying anything into an installation.
4. Use fictional inputs first. Loading a skill does not approve installation, external actions or spending.
