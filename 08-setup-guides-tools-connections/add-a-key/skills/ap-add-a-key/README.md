# Add a Key

Agentic Playbook — **by Kezy** · 0.1.0

Add keys the safe way: copy, say "copied", and the key lands in the locked file on your box. You only ever see its name.

## Before you start

Connect My Machines working (`ssh mybox`), a Mac laptop clipboard, and the service key ready to copy. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Run the key drill with a fake demo value for EXAMPLE_TOOL_API_KEY. Show me the plan first.

Expected output: The pipe command (with `$(pbpaste)`, never the value), a silent presence check, and a masked confirmation.

## Limits and permissions

No value is ever printed, pasted or written anywhere except the locked file. A key that touched a chat is treated as exposed: replace it at the service. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Included dependencies

- [Connect My Machines](../../../connect-my-machines/README.md) — required.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
