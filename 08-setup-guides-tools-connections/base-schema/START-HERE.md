# Base Schema — start here

**by Kezy**

1. Read [the package guide](README.md).
2. Read [the skill README](skills/ap-base-schema/README.md) and [installation note](skills/ap-base-schema/INSTALL.md).
3. Validate and rehearse the included fictional example.
4. Use the interview to identify the repeated unit of work and the 3–6 metrics the owner needs.
5. Draft the Record Home Map, blueprint, SQL, and manifest for review.
6. Stop before creating a real database or loading real records; those steps need explicit owner approval.

The example numbers are test fixtures, not business evidence. Never substitute invented values for missing real inputs.
