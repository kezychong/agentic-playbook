# Connect My Machines

**Agentic Playbook — by Kezy**

A private hallway between your laptop and your always-on box: both join one Tailscale network, then the laptop agent gets key-only access to the box under one short name. After that, everything on the box is one plain sentence away. Stage 3 of the [Build Track](../../02-the-2nd-brain/TRACK.md). A local source draft, not an installed or runtime-tested system.

## Included skills
- [Connect My Machines](skills/ap-connect-my-machines/README.md): Join laptop and box in one private network, then set up key-only SSH so the laptop agent can reach the box by name.

## Setup
1. Read each included skill README and its prerequisites.
2. Keep every skill folder and all its support files together.
3. Review the documented host setup before copying anything into an installation.
4. Use fictional inputs first. Loading a skill does not approve installation, external actions or spending.
