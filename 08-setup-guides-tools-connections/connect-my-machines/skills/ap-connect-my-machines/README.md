# Connect My Machines

Agentic Playbook — **by Kezy** · 0.1.0

Your laptop reaches your box from any network, with no password, under one short name.

## Before you start

Two machines you own, a free Tailscale account, and a coding agent on the laptop. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Explain the Connect My Machines steps for my laptop and a fictional box. Run nothing yet.

Expected output: Plain-English steps for both parts, with the one moment the owner types the box password.

## Limits and permissions

The box password is typed once, by the owner, into the system prompt that asks for it, never into chat. Opening a dashboard uses a tunnel, never a public port. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Included dependencies

- [Server Setup](../../../server-setup/README.md) — the box being connected.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
