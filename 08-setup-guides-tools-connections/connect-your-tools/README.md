# Connect Your Tools

**Agentic Playbook — by Kezy**

Your brain only knows what reaches it. List every tool you use, pillar by pillar, pick the safest read route for each, connect them, then add each one to the nightly capture. Read-only access is enough. Stages 8 and 9 of the [Build Track](../../02-the-2nd-brain/TRACK.md). A local source draft, not an installed or runtime-tested system.

## Included skills
- [Connect Your Tools](skills/ap-connect-your-tools/README.md): List every business tool by pillar, pick each one's read route, and connect the ones with a connector, plugin or MCP.
- [Connect to Capture](skills/ap-connect-to-capture/README.md): Link WhatsApp through WhatsApp Web and give the nightly capture one reader per connected tool.

## Setup
1. Read each included skill README and its prerequisites.
2. Keep every skill folder and all its support files together.
3. Review the documented host setup before copying anything into an installation.
4. Use fictional inputs first. Loading a skill does not approve installation, external actions or spending.

[Host setup guide](../../08-setup-guides-tools-connections/manual-setup.md)

## Companions
- [Add a Key](../add-a-key/README.md) — required for every tool marked `needs a key`.
- [Capture Bot](../../02-the-2nd-brain/capture-bot/README.md) — runs the nightly capture the feeds join.
- [WhatsApp Capture](../../02-the-2nd-brain/whatsapp-capture/README.md) — the separate two-hourly WhatsApp route, if you prefer it.
