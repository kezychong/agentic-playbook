# Connect to Capture

Agentic Playbook — **by Kezy** · 0.1.0

Every connected tool joins the one nightly capture you already have. No new timer.

## Before you start

Connect Your Tools done, Capture Bot's nightly capture approved, and a browser the box can drive for WhatsApp Web. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Show me the reader you would write for a fictional project tool. Write nothing yet.

Expected output: A short read-only reader plan and the one line added to the nightly capture prompt, awaiting approval.

## Limits and permissions

WhatsApp Web marks opened chats as read; the owner must accept that first. Passwords are typed only on each tool's own page. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Included dependencies

- [Connect Your Tools](../ap-connect-your-tools/README.md) — required.
- [Capture Bot](../../../../02-the-2nd-brain/capture-bot/README.md) — required.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
