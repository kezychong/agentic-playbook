# Connect Your Tools

Agentic Playbook — **by Kezy** · 0.1.0

One table of every tool you use, how your brain can read it, and whether it is connected.

## Before you start

The eight-door brain and Hermes on the box. Read-only access is enough for every tool. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> List the tools for fictional Company A by pillar and pick a route for each. Connect nothing.

Expected output: A `Tool | Pillar | Kind | What lives there | Route | Why | Status` table with every status `not checked`.

## Limits and permissions

It never asks for, shows or stores a key; keys go in only through Add a Key on the laptop. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Included dependencies

- [Add a Key](../../../add-a-key/README.md) — for tools that take a key.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
