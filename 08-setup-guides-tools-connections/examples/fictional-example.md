# Fictional offline report rehearsal

Agentic Playbook — by Kezy

Input: Company A completed 2 of 5 preparation steps. Three steps remain: collect the approved
brief, review the draft and choose a publication date. Publication has not been authorized.

Trigger: “Use ap-html-output to make an offline status page and Markdown sidecar from these
fictional facts. No network, account setup or publication.”

Expected result: a local self-contained HTML page with a 40% progress indicator explicitly
labelled “2 of 5 steps,” all five milestones, an honest next action and a sidecar. Decision controls
start unanswered, record choices locally and do not execute them. No remote fonts or trackers.

The [included HTML demonstration](../html-output/skills/ap-html-output/examples/demo.html) and
[decision-page template](../html-output/skills/ap-html-output/templates/decision-page.html) preserve the
source's richer visual system. They have not been opened or interaction-tested in this build.
Ask the host to show the loaded skill path before rehearsing; discovery is not proven by copying.
