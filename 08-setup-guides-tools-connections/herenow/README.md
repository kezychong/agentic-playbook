# here.now Publishing

**Agentic Playbook — by Kezy**

A page your agent made is a local file: you cannot open it from Telegram or send it to anyone. This package sets up a page-hosting account so an approved page becomes a link. It pairs with [HTML Output](../html-output/README.md). Stage 17 of the [Build Track](../../02-the-2nd-brain/TRACK.md). A local source draft, not an installed or runtime-tested system.

## Included skills
- [here.now Publishing](skills/ap-herenow/README.md): Publish a finished local HTML page as a link you can open on your phone, after approval, using a page-hosting service.

## Setup
1. Read each included skill README and its prerequisites.
2. Keep every skill folder and all its support files together.
3. Review the documented host setup before copying anything into an installation.
4. Use fictional inputs first. Loading a skill does not approve installation, external actions or spending.
