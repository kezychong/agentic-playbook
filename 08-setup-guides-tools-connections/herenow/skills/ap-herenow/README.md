# here.now Publishing

Agentic Playbook — **by Kezy** · 0.1.0

Turn an approved local page into a link you can open on your phone or send to someone.

## Before you start

A page-hosting account (here.now as the example), its key stored with Add a Key, and a finished HTML page. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Check this fictional report page for anything private, then tell me what you would publish. Publish nothing.

Expected output: A short content check and the publish step, awaiting a yes for that one page.

## Limits and permissions

Every publish is a separate approval; nothing private goes on a public link. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Included dependencies

- [Add a Key](../../../add-a-key/README.md) — required for the hosting key.
- [HTML Output](../../../html-output/README.md) — optional: makes the pages.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
