# Html Output

Agentic Playbook — **by Kezy**

Create offline HTML reports with clear visual decisions.

Start with [the complete workflow](SKILL.md). This public package is version 0.2.0.

## Prerequisites

An existing skill-capable host, a writable draft folder, and the task inputs described in the workflow. Only allow the files and integrations needed for this task. No account is needed for a fictional rehearsal. Copy the complete folder, including references, templates, examples, and evals. See [manual host setup](../../../manual-setup.md).

## Example trigger

> Use ap-html-output with fictional Company A inputs. Preserve every number exactly, show missing inputs, and produce a local draft. Do not install, connect, send, or publish.

## Output

A self-contained offline HTML page and Markdown sidecar. The workflow requires complete glossary coverage, symmetrical comparisons, neutral undecided decisions, and rendered desktop and phone checks.

## Limits

Browser rendering and integration support vary by host. Missing inputs remain unknown. If browser checks cannot run, report that gap. Live changes need explicit approval. Loading this package does not install software, connect an account, or publish a page.
