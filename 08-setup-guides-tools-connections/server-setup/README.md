# Server Setup

**Agentic Playbook — by Kezy**

Your agents need one computer that never sleeps. Pick one road: rent a small server, or turn a spare Mac mini into a headless box. Either way your laptop stays your own, and the box becomes `my box`. Stage 2 of the [Build Track](../../02-the-2nd-brain/TRACK.md). A local source draft, not an installed or runtime-tested system.

## Included skills
- [Hermes Server Setup](skills/ap-hermes-server-setup/README.md): Rent a plain Ubuntu server, reach it by key, install Hermes and Claude Code, and get the first hello.
- [Mac Mini Setup](skills/ap-mac-mini-setup/README.md): Turn a spare Mac mini into a headless agent box and hand the laptop one file to connect.

## Setup
1. Read each included skill README and its prerequisites.
2. Keep every skill folder and all its support files together.
3. Review the documented host setup before copying anything into an installation.
4. Use fictional inputs first. Loading a skill does not approve installation, external actions or spending.

[Host setup guide](../../08-setup-guides-tools-connections/manual-setup.md)
