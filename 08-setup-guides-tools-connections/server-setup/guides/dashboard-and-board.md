# Dashboard and task board tour

**Agentic Playbook — by Kezy**

Most agent hosts ship a web dashboard on the box. Open it from your laptop through [Connect My Machines](../../connect-my-machines/README.md) (a tunnel to the box's local dashboard port), never by opening the port to the internet.

## What you will find

| Area | What it is for |
|---|---|
| Sessions | Every chat, from any channel. Resume one instead of starting over. |
| Logs | What actually ran and what failed. Read these before guessing. |
| Scheduled jobs | Every timer on the box. Should match the jobs list in your brain's `AGENTS.md`. |
| Skills | What the agent can load. Installing or removing one is a live change. |
| Profiles | Your helper bots, each with its own memory and model. |
| Board | A task board for rough to-dos. |

## The task board: dump, then triage

1. **Dump.** Throw rough one-line tasks or voice notes onto the board. No sorting.
2. **Triage.** Ask the agent to sort each card against your goals: do now, delegate, park, or drop. It proposes; you approve.
3. **Specify.** For each card you keep, the agent writes what done looks like and who (or which helper) does it.
4. **Delegate.** Only approved, specified cards are handed to a helper. Finished cards come back for your review.

The board is a planning surface. A card on it never authorises sending, spending, publishing or deleting.
