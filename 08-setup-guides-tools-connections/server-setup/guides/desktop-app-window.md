# The desktop app as a window

**Agentic Playbook — by Kezy**

On your phone you talk to your agent through [Telegram Topics](../../telegram-topics/README.md). At your desk, use the agent's desktop app. The app is only a **window** onto the agent already running on your box. It must not install a second agent on your laptop.

## Set it up

1. Download the desktop app from the agent's official site and open it once. Do not click its own "install the agent" button.
2. If it asks you to choose an AI provider, choose "later". The agent on your box already has one.
3. Ask your coding agent on the laptop: "I downloaded the desktop app. Connect it to the agent on my box so the app is a window onto it. Show me each step first." If the coding agent needs to click through the app, allow screen control only for this job, and stay at the laptop.
4. Check: a chat you started on Telegram appears in the app's session list. Carry on the same conversation from the laptop.

## Using it well

- Pin what you are working on; unpin it when done. The pinned list doubles as a short to-do list.
- One helper agent per job beats one agent doing everything: each keeps its own memory.
- Skills, scheduled jobs and settings live in the app too. Changing any of them is a live change: approve it first.
