# Where schedules run

**Agentic Playbook — by Kezy**

**The rule: one always-on machine runs every scheduled job. Every other device only edits.**

Scheduled jobs (the nightly capture, the Link, Organise and Signal chain, a weekly checkup, a morning page) fire at a fixed time with nobody watching. If the machine that holds them is asleep, they do not fire. If two machines both hold them, the folder sync turns the clash into duplicate files.

## Pick one layout

| Layout | Runs the schedules | Only edits |
|---|---|---|
| Home Mac mini + laptop | The Mac mini (always plugged in, never sleeps) | The laptop |
| Rented server + laptop | The server | The laptop or desktop |
| One machine that stays on | That machine | Nothing else to sync |

Add a laptop later? Set up [Brain Folder Setup](../../../02-the-2nd-brain/second-brain-v3/skills/ap-brain-folder-setup/README.md), but keep the schedules where they are.

## Why not the laptop

1. **The lid was closed.** The 06:00 job never ran, and nobody noticed for days.
2. **It was offline.** A job that needs the internet failed on a train.
3. **Two copies ran.** The laptop and the box both fired, and the brain filled with near-duplicates.

## Check it

- List every scheduled job on every machine. Exactly one machine should have any.
- Each job appears once, in the brain's `AGENTS.md` jobs section: what it does, when it runs, which bot runs it.
- Turning a schedule on, moving it or deleting it is a separate approval each time.
