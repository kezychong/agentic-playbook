# Hermes Server Setup

Agentic Playbook — **by Kezy** · 0.1.0

A rented Ubuntu server becomes your always-on agent box, reached from your laptop by key, with Hermes saying hello.

## Before you start

A laptop with Claude Code, a browser you are signed in to, and a server plan you are willing to pay for (renting costs money: approve it yourself). Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Walk me through the rented-server setup pack as a plan only. Rent nothing and change nothing.

Expected output: The ordered parts (rent, key, walk in, install, login, hello) with what the owner must click and what the agent does.

## Limits and permissions

It never types a password, never prints a key, token or server address, and never clicks a host's own one-click agent installs. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Included dependencies

- [Connect My Machines](../../../connect-my-machines/README.md) — optional: private network access from anywhere.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
