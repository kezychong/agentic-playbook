# Telegram Topics

**Agentic Playbook — by Kezy**

Talk to your always-on agent from your phone. Make your own Telegram bot, let only your own account use it, then turn one private group into many rooms, one per subject, so a money chat never mixes with a brain chat. Stage 3 of the [Build Track](../../02-the-2nd-brain/TRACK.md). A local source draft, not an installed or runtime-tested system.

## Included skills
- [Telegram Topics](skills/ap-telegram-topics/README.md): Make a private Telegram bot for your agent, allow only your own account, and give each subject its own room.

## Setup
1. Read each included skill README and its prerequisites.
2. Keep every skill folder and all its support files together.
3. Review the documented host setup before copying anything into an installation.
4. Use fictional inputs first. Loading a skill does not approve installation, external actions or spending.
