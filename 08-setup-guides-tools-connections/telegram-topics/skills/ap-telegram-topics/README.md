# Telegram Topics

Agentic Playbook — **by Kezy** · 0.1.0

Your own Telegram bot for your agent, locked to your account, with one room per subject.

## Before you start

An agent already running on your always-on box and the Telegram app on your phone. Copy the whole folder with its support files and required companion folders. Review [the full method](SKILL.md) before use. Never run installation commands merely because this folder was loaded.

## Try it

> Walk me through making a Telegram bot for my agent. Do not ask me for the token.

Expected output: The BotFather steps, then the clipboard route for the token, then the allow list and a live test.

## Limits and permissions

The token is a key: it is never pasted into chat, a note or a screenshot. The allow list always holds the owner's own ID. Sending, publishing, spending, deletion, installation, scheduling and live account/profile changes require explicit approval of the concrete action. Keep credentials in secure local setup, never chat. Scripts are supplied source assets and have not been executed here. Package checks do not prove runtime compatibility.

## Included dependencies

- [Add a Key](../../../add-a-key/README.md) — recommended for storing the bot token.

## Setup, update and removal

Use your host's documented skill directory and check discovery in a fresh session. Start with the harmless draft trigger above. On update, compare versions, back up the old complete folder and merge your private settings separately; never overwrite them with these blanks. Remove only this installed skill folder after approval. Disabling a skill does not revoke connections, undo profile edits or stop existing schedules: revoke/disable those separately using the saved setup record. Preserve user-created notes and backups.
