# Agentic Playbook

**by Kezy**

Build your AI assistant, second brain and team.

This collection brings reusable skills, setup guides, blank templates and worked examples into one place. Start with one useful task, then add only the tools and roles you need.

> **Source collection — runtime untested.** Scripts and live connections have not been executed as part of this preparation. Do not assume every skill works on every AI host.

## What you get

- Topic guides for people.
- Reusable skill folders for agents.
- Templates and fictional examples.
- Topic package definitions that share one version of each skill.

The Finance section centres on the Finance Agent, not a generic accounting skill library. It includes an onboarding path, safety agreement, account-connection guides and reporting workflows. All connections and financial actions require appropriate human approval.

## What this is not

This is not an export of anyone's private assistant or knowledge store. It does not include live credentials, personal financial records, chats or private business settings. It is not a guarantee that connected services process data locally. Review each tool's permissions and data handling before using real information.

Loading a skill does not authorise it to publish, send messages, spend money, delete files or change a live system. Source instructions and example commands must be reviewed before use.
